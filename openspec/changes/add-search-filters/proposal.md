## Зачем

Контент-менеджерам нужно быстро находить статьи по комбинации параметров: автор, тег, дата публикации, статус модерации. Сейчас поиск работает только по заголовку, и приходится листать сотни результатов, чтобы найти нужное.

## Что меняется

- Добавляется панель расширенных фильтров над списком статей.
- Можно комбинировать фильтры по автору, тегам, диапазону дат и статусу.
- Результаты обновляются мгновенно при изменении фильтров.

## Возможности

### Новые возможности

- `article-search`: расширенный поиск статей с комбинируемыми фильтрами.

### Изменённые возможности

- `article-list`: список статей поддерживает серверную фильтрацию вместо клиентской подстроки.

## Влияние

Изменение затрагивает `article-service` и `search-index`. Производительность списка статей улучшится за счёт серверной фильтрации.
