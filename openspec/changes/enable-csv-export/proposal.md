## Зачем

Аналитикам контента нужно выгружать результаты в Excel для дальнейшей обработки в сводных отчётах. Сейчас единственный способ — вручную копировать данные из web-интерфейса, что занимает минуты на каждый срез и неприемлемо для еженедельных отчётов.

## Что меняется

- Добавляется кнопка «Экспорт CSV» в карточке статьи и в общем списке.
- При нажатии генерируется CSV-файл со всеми метриками за выбранный период.
- Файл скачивается через стандартный механизм браузера.

## Возможности

### Новые возможности

- `csv-export`: возможность выгрузить показатели в формате CSV для офлайн-обработки.

### Изменённые возможности

## Влияние

Изменение затрагивает модуль отчётов `reports-service`. Пользователи получают возможность самостоятельно формировать выгрузки без обращения к разработчикам.
