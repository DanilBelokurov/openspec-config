## Зачем

Контент-менеджерам нужно сохранять отдельные статьи в PDF для отправки партнёрам и в архив. Сейчас статьи доступны только в web-интерфейсе, и единственный способ получить файл — печать в браузере с последующим «сохранить как PDF», что даёт разные результаты в разных браузерах.

## Что меняется

- Добавляется кнопка «Экспорт в PDF» в карточке статьи.
- При нажатии backend формирует PDF с фирменным оформлением (логотип, header, footer с датой).
- Файл скачивается через стандартный механизм браузера.

## Возможности

### Новые возможности

- `pdf-export`: серверный экспорт одиночной статьи в PDF с фирменным стилем.

### Изменённые возможности

- `article-detail`: карточка статьи получает новую кнопку «Экспорт в PDF».

## Влияние

Изменение затрагивает `article-service` (новая ручка) и шаблонный движок. PDF-рендеринг выполняется на backend, чтобы результат был одинаковым во всех браузерах.
