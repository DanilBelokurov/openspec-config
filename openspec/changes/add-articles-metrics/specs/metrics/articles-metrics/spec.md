## ДОБАВЛЕННЫЕ ТРЕБОВАНИЯ

### Требование: Доступен показатель количества добавленных статей
Система ДОЛЖНА предоставлять заказчикам и ответственным за развитие контента показатель количества статей, добавленных за выбранный период.

#### Сценарий: Расчёт показателя за выбранный период
- **КОГДА** пользователь выбирает начальную и конечную даты периода
- **ТОГДА** система показывает количество статей, добавленных в пределах выбранного периода

#### Сценарий: В выбранный период статьи не добавлялись
- **КОГДА** в выбранном периоде отсутствуют добавленные статьи
- **ТОГДА** система показывает нулевое значение показателя

#### Сценарий: Сравнение показателей за разные периоды
- **КОГДА** пользователь последовательно выбирает разные периоды
- **ТОГДА** система для каждого периода показывает показатель, рассчитанный только по статьям, добавленным в соответствующем периоде
